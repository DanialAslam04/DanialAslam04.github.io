02 / Approach

An agent reasons freely. What it can reach, and what it can commit without asking, is decided before it ever runs.

01
The caller carries identity.
Not the agent. The agent never holds credentials it could reach past. Everything downstream inherits the boundary the caller arrived with.
02
A role-filtered toolset bounds what it can see.
It reasons freely inside a boundary it cannot widen. An MCP tool server stamps the caller's identity onto every call it makes.
03
Policy decides what commits.
Not a human rubber-stamping everything. A deterministic policy classifies the write, and only the ones that matter ever stop.
